## ★ 최종 선정 (파격 노선 · 창의60/실현40) — 문서 08
**「창업하지 마라, 인수하라」 — 청년 기업승계 국가 서치펀드(K-Search Fund)**
후계자 없어 사라지는 흑자기업 **67.5만 개**를 국가 서치펀드로 청년에게 **인수·승계**시켜, 맨손창업 90% 실패와 흑자기업 소멸을 동시에 없애고, 인구감소로 남는 생산자본을 청년에게 이전하는 **'제3의 커리어(인수·경영)'**. 채점 1위(창의9/실현9=9.0).
> 후킹: **"청년이여, 창업하지 말고 대표가 되라 — 국가가 회사를 사드린다."**
> (대안: 문서 07의 2위 '국가가 실패를 산다(네거티브 특허)', 3위 '상속 타이밍 역전')
