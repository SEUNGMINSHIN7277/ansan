# 청년 정책 아이디어 공모전 「내가 대통령이라면」 — 작업 저장소

> 대통령직속 **국민경제자문회의(NEAC)** 주최 · **정책제안서 부문** · 3인 이하 팀
> 접수 마감 **2026. 7. 8.(수)** / 예선 7.16 / 멘토링 7.17~20 / 본선·시상 7.27

## 선정 정책 (대상 후보) — v2 (레드팀 검증 반영)
**「채용을 먼저 약속하는 나라 — 청년 검증채용 협약 & 커리어 원장」**
신호만 만들지 않는다. SW산업 고용주 연합이 검증역량 청년을 **먼저 뽑기로 약속**(면접쿼터 사전확약 + '인정만 하고 안 뽑으면 검증권 박탈'하는 스킨인더게임)하고, 효과를 **RCT로 실증**한 뒤, SSAFY 등 성공모델을 개인소유 **커리어 원장**으로 전국 확장.
> v1(신호 인프라 중심)은 적대적 레드팀에서 '수요측 병목 오진·재정중립 형용모순·백화점식' 지적 → **수요측 확약 + 범위축소 + RCT + 정직한 재원**으로 피벗(문서 05 §4).
