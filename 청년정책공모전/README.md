# 청년 정책 아이디어 공모전 「내가 대통령이라면」 — 작업 저장소

> 대통령직속 **국민경제자문회의(NEAC)** 주최 · **정책제안서 부문** · 3인 이하 팀
> 접수 마감 **2026. 7. 8.(수)** / 예선 7.16 / 멘토링 7.17~20 / 본선·시상 7.27

## ★★★ 대상판 최종 접수본 (대상권 확정) — 문서 11
**「먼저 도착하는 국가」 — 신청주의의 종언, 청년정책 디폴트 지급 전환**
3,000개 청년정책의 전달을 pull(신청)→push(도착)로 역전: ①수급률 국가통계 신설·공시 ②정량요건 정책 '사전심사 완료→원클릭 수령' ③최하위 정책부터 옵트아웃 자동지급 시범. **신규 현금성 예산 0원.**
> 후킹: **"세금은 국가가 알아서 걷어가면서, 지원금은 왜 청년이 증명해야 주는가."**
> **대상권 판정: ✅ 확정** — 4인 심사패널 **전원 예상 1위**(YES 1·BORDERLINE 3·NO 0), 예선 89·본선 90.3(경쟁필드 최고 87). 판정 지적사항 전량 반영 완료.
> 검증 여정: 문서 10 승계안(PASS였으나 대상권 평균 2.5위로 탈락) → 재아이데이션 채택 → 팩트 3종 검증 → 문서 11 → 재판정 전원 1위. (`/workflows` 실행 로그 5회)

## (이전 통과안·검증 기록) — 문서 10
「창업하지 마라, 이어받아라」 청년 승계고용 커리어 사다리 — 접수가능 PASS(81/100)였으나 **대상권 검증에서 평균 2.5위(최우수~우수권)로 판정**되어 대상 목표에 따라 교체됨.
