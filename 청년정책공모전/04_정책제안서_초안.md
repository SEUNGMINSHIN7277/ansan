# 【응모작 — 정책제안서】

## 1. 아이디어명
> *(과제명이 아닌 아이디어의 명칭)*

## **「청년 커리어 원장」 — 검증된 실력이 스펙을 이기는 나라**
*(부제) 경험·훈련·역량을 고용주가 인정하는 신호로 바꾸는 청년 평생 역량 인프라*

---

## 2. 핵심 아이디어 *(1문장)*

**청년이 일경험·훈련·프로젝트로 쌓은 역량을 '고용주가 직접 정의·인정하는 표준'으로 검증해, 개인이 평생 소유·이동하는 「커리어 원장」에 담고 AI가 다음 성장경로를 안내하는, 스펙 경쟁을 '검증된 실력'으로 대체하는 국가 역량 신호 인프라.**

---

## 3. 아이디어 선정 배경

### 3-1. 관련 기술 및 활용 현황
- **디지털 크리덴셜·오픈배지**: 유럽연합(2022 Council Recommendation)·싱가포르·구글 커리어 인증 등은 학습·일경험 성과를 **표준 메타데이터의 검증가능 디지털 배지**로 발급해 채용시장 신호로 유통 중. 구글 커리어 인증은 미국 고용주 **87.4%가 인정**.
- **개인 데이터 주권(마이데이터)**: 한국은 금융·공공 마이데이터 인프라를 이미 구축 → 개인이 자기 데이터를 보유·이동·선택공개하는 기술 기반 보유.
- **국내 보유 자산**: 직업훈련(HRD-Net)·구인구직(워크넷)·직무표준(NCS)·학점은행제·고용보험 DB 등 **연결만 하면 되는 공공 인프라가 이미 존재**.
- **그러나 한국은 이 기술을 '신호'로 꿰지 못하고 있다.** 학습이력을 적립하는 **평생학습계좌제**를 이미 도입했으나(2008~), 노동시장 연계·유인 부재로 **사실상 사문화**(최다 인용 통계가 2013년 계좌 20,378개)됐다.

### 3-2. 문제 배경 및 원인 분석 *(데이터)*

**(현상) 청년은 '경험'이 없어 못 뽑히고, '스펙'에 과잉투자한다.**
- 미취업 청년 취업준비 애로 **1위 = '업무경험·경력개발 기회 부족' 80.7%** (2025 미취업청년 실태조사)
- 대졸 신입 재교육비 **1인당 6,218만원·19.5개월**(기업 부담) → 대학이 못 기른 역량을 기업이 재교육, 청년은 그 공백을 **취업 사교육(연 455만원, 4년새 +109%)** 으로 메움 = **역량형성 비용의 3중 전가**
- 채용이 경력직 중심으로 이동 → 비경력자 상용직 취업확률 **월 1.4%**(경력자 2.7%의 절반), 이로 인한 **생애소득 약 5,000만원 감소**(한국은행 이슈노트 2025-1)

**(구조) 원인은 '눈높이'가 아니라 노동시장의 신호(signal) 실패다.**
- 전공-직업 불일치율 **50.1%(OECD 2위)**, 그런데 과잉학력자의 **88%는 실제 역량이 오히려 부족** → 학위(신호)는 남고 역량은 모자란 **이중 미스매치**
- 대졸 취업률 **69.5%**(인문 61.1%), 첫 취업 소요 **11.5개월(역대 최장)**, '쉬었음' 청년 **46.9만명**(20~30대 합산 첫 70만 돌파)
- 근본 원인 = **역량을 검증하는 신호가 없다.** 청년이 무엇을 '할 수 있는지'를 노동시장이 신뢰할 방법이 없어, 모두가 **학벌·스펙이라는 대리신호에 과잉투자**한다.

**(기존 정책의 실패) 이미 만들었는데 왜 안 됐나 — 3대 구조적 실패**
1. **공급자·입력에 지불**: 내일배움카드·KDT는 '수강 개시'에 선불 → 저품질·중도포기(KDT 취업률 62.6%→**54.2%**)·브로커 편취
2. **신호 발급 ≠ 역량 검증**: 마이크로디그리·오픈배지·학점은행 남발(학점은행은 2025년 '학점 장사'·부정시험으로 경찰 고발 방침), 정작 **고용주 인정·직무 관련성은 방치** → 마이크로디그리 미신청 사유 1위 "잘 몰라서 85.5%"
3. **부처 칸막이**: 교육부(학점은행·배지·K-MOOC)와 고용부(내일배움카드·NCS)로 개인 이력이 **파편화**, 이를 통합할 평생학습계좌제는 **부처 연계 부재로 사문화**

### 3-3. 문제 재정의
> 통념: "청년실업은 눈높이·의지 문제다 / 지원(돈·자리)을 늘리면 된다."
>
> **재정의: 청년 문제의 핵심 병목은 '돈의 부족'이 아니라 '검증된 실력을 노동시장에 신뢰가능한 신호로 전환하는 개인 인프라의 부재'다.** 청년이 쌓은 경험·훈련·역량이 **고용주가 인정하는 신호**로 바뀌고, **생애에 걸쳐 개인이 소유·이동**하며, **AI가 경로를 안내**할 때, 스펙 경쟁·미스매치·경력공백·사교육비의 악순환이 동시에 풀린다.

## 4. 해결방안 *(아이디어 실시를 위한 구체적 내용)*

### 4-1. 정책 개요 — 3층 구조

```
                     「청년 커리어 원장」 3층 구조
┌──────────────────────────────────────────────────────────────┐
│ ③ 연결층 (활용)   AI 커리어 코치 · 검증된 첫 경력 · 스킬퍼스트 공공채용 │
│                     ▲ 원장 데이터를 채용·성장에 연결                    │
├──────────────────────────────────────────────────────────────┤
│ ② 검증층 (신호)   산업별 '고용주 컨소시엄'이 인정하는 역량단위          │
│                     = 채용·보상에 반영되는 '살아있는 NCS' + 제3자 검증   │
├──────────────────────────────────────────────────────────────┤
│ ① 기록층 (원장)   개인 소유·이동형 마이데이터 지갑                     │
│                     학점·훈련·자격·일경험·프로젝트 → 검증가능 디지털 배지 │
└──────────────────────────────────────────────────────────────┘
        국가의 역할 = '발급자'가 아니라 '검증·상호운용·성과연동의 심판'
```

### 4-2. 구성요소 (핵심 3 + 확장 2)

**① [기록층] 검증 스킬원장** — *개인이 소유·이동하는 역량 지갑*
- 학점(교육부)·훈련이수(고용부)·자격·일경험·프로젝트 성과를 **하나의 개인 원장**에 통합, **오픈배지 국제표준(검증가능 디지털 크리덴셜)** 으로 발급.
- **마이데이터 원칙**: 개인이 소유·이동·**선택적 공개**(원하는 역량만 기업에 제출). 발급주체를 재편하지 않고 **개인 주권으로 부처 칸막이를 우회**.

**② [검증층] 고용주 인정 역량단위** — *차별성의 심장*
- 반도체·SW·바이오·콘텐츠 등 **산업별 고용주 컨소시엄**이 "우리는 이 역량단위를 채용·보상에 인정한다"를 **직접 정의·서명**. NCS를 컨소시엄이 실시간 갱신하는 **'살아있는 표준'** 으로 전환.
- 성과는 **제3자 검증**(실측·표절/부정 방지). → 평생학습계좌제가 실패한 '노동시장 연계'를 **수요자(고용주)가 주도**하도록 구조를 뒤집음.

**③ [연결층] 검증된 첫 경력** — *신입의 경력공백 해소*
- 국가 일경험·직무 트라이얼 성과를 **'검증된 경력 N개월'로 공인** → 미채용되더라도 경력으로 인정. 경력직 선호(BOK)로 배제되는 **'경력 사다리의 첫 칸'을 국가가 생산**.

**④ [연결층·확장] AI 커리어 코치** — *기회격차 해소*
- 원장 데이터 기반 **개인 맞춤 로드맵**(부족역량·추천 일경험·훈련경로). 사교육이 독점한 진로·취업 정보를 **공공재로** 전환 → 소득·지역 격차(상위권대 진학률 격차 **5.4배**) 완화. 오프라인 거점(대학일자리센터·평생학습관) 병행.

**⑤ [연결층·확장] 성과연동 재정** — *재정중립*
- 훈련기관 지불을 **성과 후불**(취업·근속·임금상승 달성 시 지급)로, 저소득 청년 재교육 소득보전을 **완주·성과 조건부**로 재편. 신규 재원이 아니라 **기존 예산의 지불방식 전환**.

### 4-3. 청년의 경험 변화 *(순서도)*

```
[기존]  스펙 쌓기(자비 사교육 455만원) → 서류·필기 → "경험 없음"으로 탈락
        → 재도전 → 첫취업 11.5개월 → 직무 안 맞아 66.8% 조기이탈 → 쉬었음
                              ▼
[제안]  ① 원장 개설 → ② AI코치가 '목표직무 대비 부족역량·추천경험' 진단
        → ③ 국가 일경험/훈련 이수 → 성과가 '고용주 인정 역량단위'로 검증
        → ④ 원장에 '검증된 경력'으로 적립 → ⑤ 기업이 원장 열람·역량채용
        → 미스매치·사교육비↓, 첫취업 단축, 근속↑
```

### 4-4. 추진체계 *(거버넌스)*
- **총괄**: 국무조정실 청년정책조정위원회 산하 전담단 *(부처 칸막이 극복 — 평생학습계좌제 실패의 근본원인 해소)*
- **협업**: 고용부(HRD-Net·워크넷·NCS·고용보험DB) + 교육부(학점은행·대학) + 과기정통부(마이데이터·디지털인증) + 산업부(산업별 인적자원개발위원회 ISC)
- **근거법 정비**: 청년기본법, 국민 평생 직업능력 개발법, 전자정부·마이데이터 관련법 (발급주체 재편 없이 표준·연계 근거만 신설 → 입법 부담 최소)

### 4-5. 단계별 로드맵
| 단계 | 기간 | 핵심 과제 |
|---|---|---|

### 5-2. 정량 기대효과 *(가정 명시 추정 — 발표 시 보수적 제시)*
> ※ 아래는 인용 통계에 근거한 **방향성 추정**이며, 정밀 추계는 시범사업 데이터로 보정.
- 스펙 사교육 경험자(42.9%)의 사교육비를 일부만 대체해도 **연 수천억 원대 가계 부담 경감** (취업준비 사교육 시장 규모 기준)
- 첫취업 소요 11.5개월을 유의미하게 단축 시 → 청년 1인당 소득 창출 조기화 + 이력현상(생애소득 5,000만원 손실) 완화
- 훈련 지불의 성과연동 전환 → 기존 훈련예산(내일배움카드·KDT 등 조 단위)의 **사중손실 비율만큼 재정효율 개선**

### 5-3. 예상 문제점 및 대응방안
