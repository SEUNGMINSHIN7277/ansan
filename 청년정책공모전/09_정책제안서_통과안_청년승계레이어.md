> 검증 루프(문서 07·08 후보 4종 팩트체크+냉정심사) 결과, #1(서치펀드)이 팩트 최상위·통과 근접으로 선별됨. 검증관 처방(독창성 재정의·팩트 교정·거버넌스 전환·역선택 방어·조세형평·주제적합)을 **전면 반영**한 통과안.

# 【응모작 — 정책제안서】

## 1. 아이디어명
## **「창업하지 마라, 인수하라」 — 정부가 놓친 '살 사람'을 길러내는 청년 승계 국가 프로젝트**
*(부제) 기업승계 M&A 특별법의 빈칸 = '청년 매수자'. 국가가 청년을 '대표 후보'로 길러 흑자기업을 잇게 한다.*

---

## 2. 핵심 아이디어 *(1문장)*
**정부가 2025년 말 입법에 착수한 '기업승계 M&A 특별법'이 매도자·기업 지원에 머무는 사이, 정작 흑자기업을 이어받을 '청년 매수자(서처)'에게는 진입자본·훈련·매칭이 전무하다 — 이 빈칸을 국가가 '지분형 탐색자금 + 청년 승계사관학교 + 민간위탁 서치펀드-of-펀드'로 채워, 청년을 창업의 90% 실패가 아니라 검증된 흑자기업의 '대표'로 데뷔시키는 수요측 파이프라인.**

---

## 3. 아이디어 선정 배경

### 3-1. 관련 기술 및 활용 현황 *(정직한 현황 — 차별성의 출발점)*
- **민간은 이미 시작했다**: 「한국서치펀드」(2021 설립)가 **국내 1호 딜**로 후계자 없는 흑자 중기를 인수하고 서처가 대표로 취임. → 모델은 **한국에서도 작동함이 실증**됨(실현성 근거).
- **정부도 이 방향으로 간다**: 2025.12 경제관계장관회의가 **「M&A를 통한 중소기업 승계 촉진 특별법」**(2026 상반기 입법 목표)을 발표 — 친족→**제3자 M&A 승계 확대**, 기업승계지원센터, 자금보증·정책금융 우대, 보조금, 기보 M&A 플랫폼.
- **그러나 결정적 공백**: 민간 서치펀드는 **소수 엘리트**만, 정부 특별법은 **매도자·기업(공급측)** 중심. → **"살 사람(청년 매수자·searcher)"을 국가가 길러 진입시키는 수요측 파이프라인은 어디에도 없다.** 이것이 본 제안의 정확한 자리.
- 해외: 서치펀드(스탠퍼드 1984~), **일본 사업승계 국책**(2008 세제·2018 특례·전국 인계지원센터) — 제3자 승계를 국가가 제도화한 선례.

### 3-2. 문제 배경 및 원인 분석 *(교정된 데이터)*
| 문제 | 데이터(교정·출처) |
|---|---|
| **흑자기업의 조용한 소멸** | 60세+ CEO 중소기업 236만 중 후계 부재 **약 67.5만 개**(중기중앙회 인용; 대안추정 21만도 존재). **중소제조업** 대표 60세+ 비율 2013 15.9%→2023 **36.8%**. 승계 못하면 **폐업·매각 고려 56.2%** |
| **청년 창업의 높은 실패** | 국내 신생기업 5년 생존율 **34.3%**(OECD 45.4% 하회); **청년(30세 미만) 5년 생존율 15.9%(≈84% 실패)** *(주: '90% 실패'는 미국 스타트업 통계로 국내엔 부정확 → 국내치로 교정)* |
| **겁 없는데도 안정 쏠림 = 합리적 계산** | 청년 안정선호(대기업28.7+공기업18.6+국가기관15.8=**63.1%**, 2025 통계청). 그런데 GEM상 한국 성인 창업 실패두려움은 세계 최저권(29.2%) *(주: '청년' 세분화 아닌 전체 성인 지표)*. → **겁이 없는데도 안정을 택하는 이유는 '재기·진입 자본의 부재'라는 구조적 계산.** |
| **인구절벽 = 자본은 남고 사람이 없다** | 잠재성장률 2030년 1% 초반·2040년대 0%대(KDI); 생산연령인구 2021~30 **320만 감소**; 20대 2005~25 **694→575만(-17%)** |

### 3-3. 문제 재정의
> 통념: "청년 일자리는 **새 일자리(창업)**를 만들어 푼다." / 최근 통념: "기업승계는 **매도자·세제** 문제다."
>
> **재정의: 인구가 줄어 자본(흑자기업)이 남아도는 시대의 진짜 병목은 '살 사람'이다. 정부는 '팔 사람(매도자)'을 돕지만, '이어받을 청년 매수자'를 길러내지 않는다. 청년에게 필요한 것은 창업도 세제도 아닌, '대표로 진입할 자본·훈련·매칭'이다.** 국가가 청년을 '검증된 흑자기업의 대표 후보'로 길러내면, 흑자기업 소멸과 청년 창업 실패가 동시에 풀린다.

## 4. 해결방안 *(구체적 내용)*

### 4-1. 포지셔닝 — 정부 특별법 '위에 얹는' 청년 수요자 레이어
```
   [정부 M&A 승계 특별법 (2026~, 공급측)]     ← 이미 추진 중(실현성·시의성 증거)
     매도자 세제 · 기업승계지원센터 · M&A 플랫폼 · 자금보증
                    ▲  빈칸: "살 청년(매수자)"이 없다
   ┌───────────────┴───────────────────────────┐
   │   본 제안 = 청년 매수자(searcher) 레이어      │
   │   ① 지분형 탐색자금(부채 아닌 투자)           │
   │   ② 청년 승계사관학교(교육·일자리 트랙)        │
   │   ③ 민간위탁 서치펀드-of-펀드(정부 직접운용 X) │
   │   ④ 역선택·좀비 차단 스크리닝 + 성과연동 회수   │
   └───────────────────────────────────────────┘
```

### 4-2. 4대 구성요소 (검증 결함 방어 내장)
**① 지분형 탐색자금** — 청년 서처의 1~2년 탐색기(생활비·실사비)를 **수당이 아니라 지분 투자**로. 성공 시 회수, 실패 시 청년 **부채 미발생**(하방 제한). *(정부 특별법엔 없는 '청년 진입자본')*

**② 청년 승계사관학교** — M&A·재무·실사·조직경영 실전 교육 + **전(前) 대표 6~12개월 도제 인계**. → **취업·교육 분야 정면 부합**(청년 역량형성 트랙), 청년 경영역량 부족 리스크 방어.

**③ 민간위탁 '서치펀드-of-펀드'** — 정부가 PE를 직접 운용하지 않는다. **모태펀드형으로 민간 서치펀드에 재간접 출자**(운용·딜소싱은 민간). → 정부 직접운용의 거버넌스·이해상충 리스크 방어.

**④ 역선택·도덕적해이 차단 설계** — (a) 저성장·마이너스 현금흐름 **좀비기업 배제 스크리닝** (b) 국가보증+셀러파이낸싱 **중첩 한도** + 매도자 **어닝아웃·후순위**(매도자도 성공에 이해관계) (c) **성과연동 국가지분 회수**. → 우량기업이 민간으로, 부실이 국가로 몰리는 역선택 차단.

### 4-3. 청년의 여정 *(순서도)*
```
승계사관학교 선발 → 지분형 탐색자금으로 흑자기업 발굴·실사(좀비 배제)
 → 인수금융(민간펀드 재간접+셀러 어닝아웃+보증 한도) → 대표 취임(전대표 도제 인계)
 → 경영 안정화 → AI·자동화 생산성 도약 → (성공)국가지분 성과회수·재투자 / (실패)지분구조 하방제한·재도전
```

### 4-4. 기존/정부안과의 차별 *(비교표)*
| 구분 | 맨손 창업 | 한국서치펀드(민간) | 정부 M&A 승계 특별법 | **본 제안(청년 수요자 레이어)** |
|---|---|---|---|---|
| 대상 | 청년 개인 | 소수 엘리트 서처 | **매도자·기업** | **청년 매수자 다수 + 국가 양성** |
| 진입자본 | 청년 부채 | 민간투자자 | (지원 없음) | **지분형 탐색자금(부채 X)** |
| 훈련 | 없음 | 개인 역량 | 없음 | **승계사관학교(교육·취업 트랙)** |
| 국가 역할 | 창업보조금 | 무관 | 매도자 세제·보증 | **재간접 출자+양성+매칭+회수** |

### 4-5. 추진체계·로드맵·재원 *(정직)*
- **추진체계**: **중소벤처기업부** 주관(정부 특별법과 연계) + 모태펀드(재간접 출자) + 기보·신보(보증) + 기재부(청년 승계세 감면). *국가는 운용자가 아니라 출자자·양성자·회수자.*
- **로드맵**: (1년) 승계사관학교 1기 + 지방 흑자 제조업 **파일럿(소규모, 손실 시나리오 base/stress 설정)** → (2~3년) 정부 특별법 시행과 연동 확대·민간 공동출자 → (4~5년) 청년 승계 생태계 정착.
- **재원(정직 산정)**: ① 재간접 출자는 **회수형 지분**(재정 지속) ② 청년 승계세 감면은 **상한·일몰 + 재정추계** 동반, 차등 근거 = 청년 진입장벽·세대간 자본이전의 **양(+)의 외부효과**(부자감세 아님을 데이터로 방어) ③ 파일럿 운영비. **재정중립을 과장하지 않되, 회수형·세원존속으로 순비용이 낮음을 명시.**
> ※ 서치펀드 'IRR 35.1%'는 **엘리트 표본의 선택편향**이므로 본문에 지표로 쓰지 않고, **국내 파일럿의 보수적 손실 시나리오**로 대체.

## 5. 기대효과

### 5-1. 수혜자별 (기업·정부·국민·사회)
| 수혜자 | 효과 |
|---|---|
| **청년(국민)** | 창업 90% 실패 대신 **검증된 흑자기업 대표로 데뷔**; 지분형 자금으로 부채·낙인 최소; 승계사관학교로 역량 확보 |
| **기업·매도자** | 후계자 없는 흑자기업 **소멸 방지·안정 엑싯**, 종업원 **고용 승계** |
| **정부** | 정부 특별법의 **빈칸(매수자)을 저비용으로 완성**; 재간접·성과회수로 재정효율; 창업 사중손실↓ |
| **사회·경제** | **세대 간 자본 대이전** + 인구감소를 **1인당 자본심화**로 상쇄 → 잠재성장률 방어; 지역 제조업·일자리 존속 |

### 5-2. 정량 효과 *(정직·보수적)*
- 후계자 없는 **67.5만 개**(대안 21만) 중 파일럿→확산으로 매년 일부만 승계해도 **일자리·자본 존속**.
- 계속기업(going-concern) 인수는 국내 청년 창업 5년 생존율 **15.9%**를 크게 상회(현금흐름·거래처 보유).
- 국가 재정효과 = 재간접 회수 + 폐업 시 소멸할 **세원 존속**.

### 5-3. 예상 문제점 및 대응 *(검증 6대 결함 선제 방어)*
| 예상 문제 | 대응 |
|---|---|
| **"정부가 이미 한다(독창성)"** | 정부안은 **매도자·기업 중심**. 본 제안은 그 빈칸인 **청년 매수자 레이어**(진입자본·훈련·매칭) — 층위가 다르며, **정부 추진은 오히려 실현성·시의성 증거** |
| 국가 PE 운용 리스크 | **직접운용 안 함** — 민간위탁 재간접(fund-of-search-funds) |
| 역선택·좀비 연명 | 좀비 배제 스크리닝 + 보증·셀러파이낸싱 한도 + 어닝아웃·후순위 + 성과연동 회수 |
| 조세형평(부자감세 우려) | 청년 승계세 감면 **상한·일몰·재정추계** + 외부효과 근거 |
| 청년 경영역량 | 승계사관학교 + 전대표 도제 + 전문경영인 매칭 옵션 |
| IRR·실패율 과대 | 선택편향 지표 배제, 국내 보수 시나리오·정확 생존율(15.9%) 사용 |
