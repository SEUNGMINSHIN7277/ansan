# 【응모작 — 정책제안서】

## 1. 아이디어명
## **「창업하지 마라, 인수하라」 — 청년 기업승계 국가 서치펀드(K-Search Fund)**
*(부제) 대한민국 청년이 대표로 데뷔하는 가장 빠른 길 · 사라지는 흑자기업을 청년에게 잇는 '이어달리기'*

---

## 2. 핵심 아이디어 *(1문장)*
**후계자가 없어 흑자인데도 사라지는 중소기업 67.5만 개를, 국가가 '서치펀드' 방식으로 청년에게 인수·승계시켜 — 맨손 창업의 90% 실패와 흑자기업의 소멸을 동시에 없애고, 인구감소로 남아도는 생산자본을 청년에게 이전하는 '제3의 커리어(인수·경영)' 국가 프로젝트.**

---

## 3. 아이디어 선정 배경

### 3-1. 관련 기술 및 활용 현황
- **서치펀드(Search Fund)**: 1984년 스탠퍼드에서 시작된 검증된 모델. 청년 '서처(searcher)'가 투자자 자금으로 **좋은 중소기업을 찾아 인수·경영**한다. 스탠퍼드 GSB 실증 총 **IRR 35.1%·투하자본 4.5배**(VC·PE·S&P를 압도).
- **일본**: 후계자 부재 흑자기업 문제를 국가 과제로 규정, **사업승계·제3자 M&A를 국책으로 추진**(사업승계 보조금·인계지원센터·M&A 플랫폼).
- **국내**: 가업상속공제·창업지원·정책금융(중진공·기보·신보)·모태펀드는 존재하나, **① 승계는 '친족'에 편중**(비친족 청년 승계 통로 사실상 부재), **② 청년정책은 '창업(무에서 유)'에만 집중**. → **'청년이 기존 흑자기업을 인수'하는 제3의 경로가 정책 공백.**

### 3-2. 문제 배경 및 원인 분석 *(데이터)*
| 문제 | 데이터 | 출처 |
|---|---|---|
| **흑자기업의 조용한 소멸** | 후계자 없는 중소기업 **약 67.5만 개**; 60세 이상 대표 비율 2013년 15.9%→2023년 **36.8%**; 승계 못 하면 **폐업·매각 고려 56.2%** | 중기이코노미·KDB |
| **맨손 창업의 높은 실패** | 신생기업 5년 생존율 약 30%대 — 청년 맨손창업은 판로·현금흐름·인력이 0에서 시작 | 통계청 기업생멸 |
| **청년의 합리적 안정 쏠림** | 대기업 21.6%·공기업 21.5%·국가기관 20.1%(**합계 63%**) 선호. GEM: 한국 청년 **실패 두려움은 세계 최저권** — 겁이 아니라 **재기자본 단절(capital friction)** 때문에 도전을 계산상 회피 | 통계청·GEM 2024/25 |
| **인구절벽 = 자본은 남고 사람이 없다** | 잠재성장률 사상 첫 **1%대 진입**(2040년대 0%대); 생산연령인구 2021~30 **320만 감소**; 20대 인구 2005~25 **17%↓** | KDI |

**원인 종합**: 한국은 **두 개의 실패가 동시에** 진행 중이다 — ① 멀쩡히 돈 버는 흑자기업이 후계자 없어 **생산자본·일자리·기술을 소각**(조용한 폐업), ② 청년은 **맨손 창업**으로 높은 실패를 감수하거나 아예 도전을 포기(안정 쏠림). 두 실패는 **서로의 해답**인데, 이를 잇는 제도가 없다.

### 3-3. 문제 재정의
> 통념: "청년 일자리 문제는 **새 일자리를 창출**해서 푼다(창업 지원·일자리 사업)."
>
> **재정의: 진짜 기회는 '새로 만드는 것'이 아니라, 이미 존재하는 좋은 일자리(흑자기업)가 후계자 없이 사라지는 것을 청년에게 넘겨 '잇는 것'이다. 청년에게 필요한 것은 창업이 아니라 '승계'다.** 인구가 줄어 자본이 남아도는 시대에, 국가가 할 일은 청년을 맨땅에 세우는 것이 아니라 **검증된 흑자기업의 대표 자리로 데뷔**시키는 것이다.

## 4. 해결방안 *(아이디어 실시를 위한 구체적 내용)*

### 4-1. 개요 — '이어달리기' 3단계 구조
```
  [조용한 폐업 위기]                [국가 K-서치펀드]                 [청년의 도약]
  후계자 없는 흑자기업   ──매칭──▶   ① 탐색(Search)      ──지분투자──▶   청년 '서처'
  (67.5만 개, 폐업 56%)              ② 인수(Acquisition) ──보증·세감면──▶ 대표로 데뷔
                                     ③ 경영·도약(Operate)──멘토·AI──▶   생산성 도약
        │                                                                    │
        └────────  세대 간 자본·일자리·기술의 '이어달리기'  ───────────────────┘
        국가의 역할 = 대출자가 아니라 '지분 투자자 + 승계 보증자 + 매칭·검증자'
```

### 4-2. 3단계 상세 메커니즘

**① 탐색(Search) — 청년을 '대표 후보'로 훈련·파견**
- **청년 승계사관학교**: 만 19~39세 서처를 선발해 M&A·재무·실사·경영을 6개월 실전 교육(기존 창업사관학교의 승계 버전).
- **탐색자금은 '수당'이 아니라 '지분투자'**: 1~2년 탐색기간의 생활비·실사비를 국가 서치펀드가 **지분**으로 투자(성공 시 회수) → 청년 부채 미발생, 국가는 투자자.
- **매칭 플랫폼**: '후계자 없는 흑자기업 DB' ↔ 청년 서처 매칭(중진공·지자체·상공회의소 연계).

**② 인수(Acquisition) — 인수금융을 국가가 디리스킹**
- **셀러 파이낸싱**: 매도자(전 대표)가 인수대금을 **분할 수취**(성공적 인수인계의 유인) → 청년 초기 부담↓.
- **국가 인수보증 + 정책금융 레버리지**: 중진공·기보·신보가 인수금융을 보증·공동투자 → 청년 자기자본 최소화, **실패 시 하방을 지분구조로 제한**(부채 폭탄 방지).
- **★ 제3자 청년 승계세 감면(핵심 제도 신설)**: 친족에 편중된 현행 **가업상속공제**를 **'비친족 청년 제3자 승계'로 확장** — 양도·상속·증여세를 대폭 우대. (현행 상속세 최고 50%가 제3자 승계를 막는 주범)

**③ 경영·도약(Operate & Scale) — 인수 후를 국가가 받친다**
- **전(前) 대표 멘토링 6~12개월**: 거래처·노하우·인력의 안정적 인계(급단절 방지).
- **AI·자동화 도입 바우처**: 확보된 현금흐름·거래처 위에 **AI·자동화를 얹어 생산성 도약**(단순 승계를 넘어 '업그레이드').
- **실패 안전장치**: 지분·포트폴리오 구조로 청년 개인 부채·낙인 최소화(도전 안전망 결합).

### 4-3. 청년의 여정 *(순서도)*
```
선발(승계사관학교) → 탐색(흑자기업 발굴·실사, 지분형 탐색자금)
 → 인수금융(셀러파이낸싱+국가보증, 승계세 감면) → 대표 취임(전대표 멘토 인계)
 → 경영 안정화 → AI·자동화 도약 → (성공)국가 지분 회수·재투자 / (실패)하방 제한·재도전
```

### 4-4. 기존 경로와의 차별 *(비교표)*
| 구분 | 맨손 창업 | 친족 가업승계 | **청년 승계 서치펀드(제안)** |
|---|---|---|---|
| 출발점 | 무(無)에서 시작 | 가족만 | **검증된 흑자기업 + 비친족 청년 누구나** |
| 실패위험 | 매우 높음(90%) | 중 | **낮음**(현금흐름·거래처 존재 + 지분형 하방제한) |
| 자본 | 청년 부채 | 가족 자산 | **국가 지분투자·보증**(부채 최소) |
| 국가 역할 | 창업 보조금 | 상속세 공제(친족) | **지분투자자+승계보증+매칭·검증+세감면** |
| 사회적 효과 | 신규 시도 | 부의 세습 | **자본·일자리 소멸 방지 + 세대 간 자본 이전** |

### 4-5. 추진체계 · 로드맵 · 재원 *(실현가능성)*
- **추진체계**: **중소벤처기업부** 주관 + 중진공·기보·신보(정책금융·보증) + **기획재정부**(승계세제) + 산업부(업종). 'K-서치펀드'는 **모태펀드·정책금융 재편**으로 조성(신규 재원 최소).
- **로드맵**: (1년) **지방 흑자 제조업 100건 파일럿** + 승계사관학교 1기 + 승계세 감면 입법 → (2~3년) 1,000건 확대·민간 서치펀드 공동투자 → (4~5년) 전국·업종 확산, 민간 승계 M&A 생태계 정착.
- **재원(정직 산정)**: ① 국가 서치펀드(모태펀드·정책금융 재조준, **회수형 지분** → 재정 지속) ② 승계세 감면(세수의 **시점이동** — 어차피 폐업 시 소멸할 세원을 존속시켜 장기 세수 오히려 증대) ③ 파일럿 운영비(승계사관학교·플랫폼). **'재정중립'은 과장하지 않되, 회수형 지분·세원 존속으로 순비용이 낮음을 강조.**

## 5. 기대효과

### 5-1. 수혜자별 기대효과 (기업·정부·국민·사회)
| 수혜자 | 기대효과 |
|---|---|
| **청년(국민)** | 맨손창업 아닌 **검증된 흑자기업의 '대표'로 데뷔** — 제3의 커리어. 현금흐름·거래처 위에서 시작해 실패위험↓, 지분구조로 부채·낙인 최소 |
| **기업·매도자** | 후계자 없는 흑자기업의 **소멸 방지·안정적 엑싯**, 종업원 **고용 승계**, 노하우·거래처 존속 |
| **정부** | 중소기업 폐업·일자리 소멸 방지, **세원 존속**(폐업 시 소멸할 세수 유지), 창업지원 사중손실↓(성과형 지분) |
| **사회·경제** | **세대 간 자본 대이전** + 생산가능인구 감소를 **1인당 자본심화**로 상쇄 → 잠재성장률 방어; 지역 제조업·일자리 존속 → 균형발전; 청년의 안정 쏠림(63%) 완화 → 경제 역동성↑ |

### 5-2. 정량 기대효과 *(가정 명시·보수적)*
- 후계자 없는 **67.5만 개** 중 매년 일부(파일럿 100건→연 1,000건→확산)만 승계해도 **수만~수십만 일자리·자본 존속**.
- 서치펀드 실증 **IRR 35%**(스탠퍼드) → 국가 지분투자의 **회수·재투자 선순환** 가능성.
- 맨손창업(5년 생존 30%대) 대비 **승계기업 생존율 대폭 상회**(기존 현금흐름·거래처 보유) → 정책 ROI 우위.

| 대기업 위장·투기 악용 | 대상을 **중소·중견 흑자기업 + 청년 실경영**으로 한정, 전매 제한 |
