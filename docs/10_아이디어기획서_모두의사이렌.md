## ■ 아이디어 개요

### 1. 배경 — 현황과 문제점

**안산의 현실.** 안산시는 외국인 주민 101,850명, 총인구 대비 15.2%로 경기도 1위의 도시다[1]. 단원구 선부동 '땟골마을'에는 국내 최대 고려인(러시아어권) 공동체 약 2만 3천 명이 살고[2], 원곡동은 70여 개국 주민이 모인 국내 유일의 다문화마을특구다[3]. 그런데 이들의 생명을 지키는 마지막 안전장치인 **재난문자는 한국어로만 온다.** 정부가 외국인용으로 운영하는 Emergency Ready App은 영어·중국어·베트남어·태국어·일본어 5개 언어만 지원해 **안산 고려인 2만 3천 명이 쓰는 러시아어는 아예 없고**[4], 앱을 스스로 찾아 설치한 사람에게만 작동하는 '풀(pull)형' 구조다. 즉, **재난문자가 발송되어도 안산 시민 7명 중 1명에게는 사실상 닿지 않는다.**

**국가의 현실.** 이 문제는 언어에서 끝나지 않는다. 재난문자 체계 전체가 '발송'에서 멈춰 있고, '도달'은 아무도 책임지지 않는다. 실제 사례로 검증된 6가지 실패 지점이 있다.

| 실패 지점 | 검증된 실제 사례 |
|---|---|
| ① 감지 지연 | 오송 지하차도 참사(2023.7.15): 1시간 전 119 신고와 홍수경보가 있었으나 종합되지 못했고, 지하차도 경고 문자는 **사고 2시간 29분 후** 발송[5][6] |
| ② 검증 실패 | 이태원 참사(2022.10.29): 첫 신고 후 **1시간 40분** 뒤에야 첫 재난문자, 발송 요청은 78분간 처리되지 않음[7][8] / 서울 경계경보 오발령(2023.5.31): 검증 없이 발송 후 22분 뒤 '오발령' 정정[9] |
| ③ 문안 품질 | 서울 오발령 문자에는 '왜, 어디로' 대피하는지가 없었음[9]. "안전에 유의하시기 바랍니다"류의 무행동 문구 관행 |
| ④ 표적 부재 | 시군구 전체 일괄 발송 → 무관한 수신 반복 → 피로감에 **알림을 끄는 시민들**('스팸' 취급)[10] → 정작 위험할 때 못 보는 '양치기 소년' 악순환 |
| ⑤ 채널 단일 | 휴대폰 CBS 단일 의존 — 알림을 껐거나, 폰을 못 보거나(운전·작업·수면), 한국어를 못 읽는 시민에게 공백 |
| ⑥ 도달 미측정 | 국가는 '몇 건 발송했는지'만 알고 '몇 %에게 닿았는지' 모른다 — 성과지표가 없어 ①~⑤가 영원히 개선되지 않음 |

### 2. 해결의 필요성 — 왜 지금, 왜 안산인가

- **지금**: 행정안전부는 2026년 하반기 재난문자를 90자→**157자로 전국 확대**한다[11][12]. 그릇은 커졌지만, 커진 그릇을 '몇 분 만에, 무엇으로 채워, 누구에게 닿게 할지'는 여전히 담당자 개인의 손에 있다. 2026년은 AI 기본법 시행(2026.1)[13]과 맞물려 '재난 커뮤니케이션의 AI 전환'을 시작할 적기다.
- **안산**: 재난문자 발령권자에는 시장·군수·구청장이 포함되며(「재난문자방송 기준 및 운영규정」, 행정안전부 훈령)[14], 호우·폭염·한파·실종경보 등 생활재난 문자의 발령 주체가 바로 안산시다. 즉 이 아이디어는 **안산시가 자기 권한으로 즉시 실행할 수 있는 자기 업무의 혁신**이다. 동시에 안산은 하천 28개[15]와 해안 관광지(대부도), 국가산업단지의 야외 노동, 시 단위 최고 수준의 외국인 비율이 겹치는 — 재난정보 도달 문제의 최대 피해 도시이자 최적 실증 도시다.

### 3. 핵심과제

재난문자의 생애주기 6단계(감지→검증→작성→표적→전파→도달확인)를 공공데이터와 AI로 전환하고, 대한민국 최초로 재난 커뮤니케이션의 성능을 2개 지표로 측정한다.

- **TTR(Time-to-Reach)**: 위험 신호 최초 포착 → 위험 노출 시민 도달까지의 시간. 목표 **5분 이내** (오송 2시간 29분 대비)
- **Reach Rate(도달률)**: 위험 노출 인구 중 '읽고 행동할 수 있는 형태'로 받은 비율. 목표 **95% 이상** (현재 언어 기준 상한 약 85%)

### 4. 아이디어 내용 요약

> **"모두의 사이렌"은 안산시 재난문자 운영을 위한 AI 관제탑이다.** 도시의 개방 데이터(수위·기상·교통·CCTV)가 위험을 감지해 발송 검토를 발제하고, AI가 근거를 교차검증해 담당자의 확신을 만들며, 157자 문안과 러시아어를 포함한 20개 언어 행동카드를 3초 안에 작성하고, 시간대 유동인구로 발송 범위를 골목 단위로 좁히고, CBS와 동시에 도로전광판(VMS)·버스정류소·외국인 밀집 상점('동네 사이렌' 노드)·시 다국어 챗봇으로 밀어내며, 발송 직후 도달률을 계산해 다음 발송을 더 낫게 만든다. **발송 버튼은 끝까지 사람이 누른다 — AI는 시간과 확신과 도달을 만든다.**

**① 감지 — "도시가 이상을 느낀다."** 안산 관내 하천 28개(D11) 유역의 실시간 수위(D9)와 기상특보(D13), 도로 구간별 교통흐름·속도(D8)의 급변, 재난감시 목적으로 설치된 교차로 CCTV(D7) 위치 정보를 결합해, 과거 10년 구·동별 강우량(D12)으로 학습한 임계 기준을 넘는 순간 '재난문자 발송 검토' 티켓을 자동 발제한다. 오송의 교훈 — 신호(홍수경보·신고)는 있었으나 종합되지 않았다[5][6] — 에 대한 직접 응답이다.

**② 검증 — "확신을 3분 안에."** 발제된 티켓에 대해 수위+기상+교통+CCTV 화면 링크를 한 화면에 모아 신뢰도 스코어와 근거 묶음을 제시한다. 담당자는 근거를 보고 발송·보류를 결정한다(human-in-the-loop). '확신이 없어 78분을 흘려보내는 것'[7]과 '검증 없이 쏘는 오발령'[9]의 양극단을 동시에 제거한다.

**③ 작성 — "157자를 3초 안에, 승인은 사람이."** LLM이 재난 유형·위치·근거를 입력받아 157자 표준 골격 — 무엇이(재난)/어디서(장소)/누구는(대상)/어떻게(행동) + 가장 가까운 대피시설(D5, 100여 개소 좌표) — 으로 문안을 생성한다. 동시에 러시아어·우즈베크어·중국어·베트남어 등 안산 주민 국적 구성(D19) 기반 20개 언어와 쉬운 한국어(고령·아동), 음성(TTS) 버전을 만든다. 2026년 하반기 157자 전국 확대[11][12]에 맞춘 '커진 그릇을 채우는 도구'다.

**④ 표적 — "필요한 사람에게만, 그래서 신뢰를 지킨다."** 위험 반경 내 노출인구를 행정동별 내외국인 인구(D3)와 시간대·내외국인 유동인구(D4)로 계산해 발송 범위를 읍면동·골목 단위로 제안한다. 무관한 수신이 줄면 피로·차단[10]이 줄고, '진짜 경보'의 신뢰가 회복된다.

**⑤ 전파 — "CBS가 못 닿는 곳을 도시가 민다."** CBS 발송과 동시에 ▸VMS 도로전광판(D6) ▸버스정류소 안내(경기데이터드림 정류소 데이터) ▸**'동네 사이렌' 상점 노드** — 세계맛집(D14)·상품권 가맹점(D15) 좌표로 선정한 외국인 밀집 상점의 사장님 폰과 매장 화면 ▸안산시 26개 언어 행정챗봇(시 GovTech 실증사업)·외국인주민지원본부 채널 ▸공공와이파이 거점(D16)으로 언어·채널별 변형 메시지를 동시 송출한다. 폭염·한파 시엔 무더위쉼터·그늘막(D18) 안내를, 취약 골목엔 노인·독거 데이터(D17)로 채널을 증설한다.

**⑥ 도달확인·학습 — "측정이 개선을 만든다."** 발령 직후, 발령이력(D1·D2) × 노출인구(D3·D4) × 언어 구성(D19) × 채널 커버리지의 결정론적 계산으로 도달률과 TTR을 산출하고, 언어·골목·채널별 공백 리포트를 자동 생성해 ④·⑤의 파라미터를 갱신한다. 대한민국 재난 커뮤니케이션에 처음으로 '성능 지표'가 생긴다.

### 2. 공공데이터·AI 활용 작동 방식 및 분석 방안

**[도표 2] 데이터 흐름** : 수집(API 폴링/파일 적재) → 표준화(전처리) → 공간 결합(H3 격자) → 단계별 AI → 관제 대시보드 → 채널 송출 → 도달률 리포트

- **노출인구 산정식**: 격자 g, 시간 t의 노출인구 E(g,t) = 주민등록 기반 상주인구(D3, 야간 가중) + 유동인구(D4, 주간·시간대 가중). 언어별 노출 L(g,t,lang) = E(g,t) × 해당 행정동 국적 구성비(D19)
- **도달률 산식**: Reach(발령) = Σ_lang [ L(g,t,lang) × Coverage(lang, 채널조합) ] / Σ_lang L(g,t,lang). Coverage는 채널별 도달 계수(CBS 수신율, VMS 가시권 반경 300m, 정류소 대기인구, 상점 노드 반경 150m, 챗봇 구독자)로 구성 — 계수는 시범 운영에서 실측 보정
- **감지 임계**: 수위 관측치의 STL 분해 잔차 + 과거 10년 강우 분위수(D12) 초과, 교통 속도의 구간별 Z-score 급락(침수·사고 프록시) — 두 신호 이상 동시 발화 시 티켓 생성
- **검증 스코어**: 신호별 가중 로그오즈 결합(베이지안) → 0~100 스코어 + 신호 기여도(SHAP 방식 표시) → 근거 화면(CCTV 스트림 링크 포함)과 함께 제시
- **LLM 문안 생성**: 시스템 프롬프트에 157자 골격·금칙(추측 금지, 미확인 정보 표기)·재난 유형별 행동요령 템플릿(RAG: 행동요령 문서 + 대피시설 D5)을 고정, 생성문에 AI 작성 표시[13]. 다국어는 동일 의미 보존 검증(back-translation 자동 점검) 후 담당자 승인
- **커버리지 최적화**: 미도달 잔여 인구를 최대로 줄이는 채널·노드 추가 선택(greedy 근사 — 예산 제약 하 커버리지 최대화)

### 2. 아이디어의 현실성 및 지속가능성

- **현실성 ①(권한)**: 재난문자 발령권자에 시장·군수·구청장이 포함되어[14] 본 아이디어의 전 단계가 안산시 권한 내 업무다. 신규 인프라 투자 없이 시가 보유·개방한 자산(VMS·CCTV·챗봇·데이터)으로 시작한다.
- **현실성 ②(데이터)**: 본 기획서의 모든 데이터(D1~D19)는 공공데이터포털·경기데이터드림에 현재 개방되어 있음을 개별 확인했다(2026.7. 기준, URL 명기). 도달률·노출인구는 예측모델이 아닌 **개방 데이터의 결정론적 계산**이어서 데이터 표본·정확도 논쟁에 좌우되지 않는다. 유동인구(D4)는 통신 기반 추정 자료이므로 '노출 인구의 근사'로 명시하고 보조 변수로 사용한다.
- **현실성 ③(거버넌스)**: 발송 결정은 전 단계 human-in-the-loop로 담당 공무원이 수행하고 모든 판단 로그를 보존한다. AI 생성물 표시·설명가능성 제공으로 AI 기본법(2026.1 시행)[13]을 선제 준수한다.
- **지속가능성 ①(연중 운영)**: 여름 호우·폭염(무더위쉼터 D18) → 겨울 한파·대설 → 연중 실종경보·사고·미세먼지까지 동일 파이프라인이 재난 유형만 바꿔 운영된다 — 계절성 없는 상시 시스템.
- **지속가능성 ②(정책 정합)**: 행안부 157자 개편(2026 하반기 전국 확대)[11][12]의 실행 도구로서 개편 로드맵에 편승하며, 최우수 선정 시 제14회 범정부 공공데이터·AI 활용 창업경진대회 통합본선(아이디어 기획 부문)에서 '안산 실증 → 전국 표준' 서사로 연결된다.
- **지속가능성 ③(운영 구조)**: 오픈소스 스택(Python·PostGIS)+개방 API 기반이라 라이선스 비용이 없고, 지자체 공동 활용(재난문자 코파일럿 SaaS) 시 유지비를 분담하는 구조로 확장 가능하다.

## ■ (자유 기재)

**1. 왜 '안산'이 이 아이디어의 주인인가.** 안산은 '전달되지 않은 경고'의 무게를 대한민국에서 가장 깊이 아는 도시다. 세월호의 도시 안산이 "모든 시민에게, 제시간에, 알아들을 수 있는 말로 닿는 경보"의 전국 표준을 만든다는 것 — 이것은 기술 과제를 넘어 도시의 서사이며, 안산시 발전(안전도시 브랜드, 다문화 정주 여건, 산단 노동 안전)에 직결된다.

**2. 실행 준비.** 본 팀은 1차 통과 시 2차 발표(7.30)까지 실데이터 데모를 완성해 시연한다: ▸안산 관련 재난문자 발령이력(D1·D2) 리플레이 ▸골목 단위 도달 격차 지도 ▸러시아어·쉬운 한국어 행동카드 실시간 생성. 전 데이터가 무료 개방 자료이므로 별도 조달 절차가 없다.

**3. 확장 로드맵.** ▸1단계(안산 시범): 호우·폭염 시즌 병행 운영, 도달률 baseline 실측 ▸2단계(경기도): 경기데이터드림 유동인구를 활용한 31개 시군 확산 ▸3단계(전국·제도화): 행안부 재난문자 개편과 연계한 '도달률 KPI' 표준 제안 ▸4단계(글로벌): 다국어 재난 커뮤니케이션 모델로서 CAP(국제 공통경보프로토콜) 생태계 — 미국 WEA·일본 J-Alert도 표적·도달 측정은 미해결 — 에 K-재난안전 모델 수출.

**4. 데이터 개방 제언.** 본 기획 과정에서 안산시 개방 데이터 107종을 전수 조사했다. 재난문자 채널로 쓰일 VMS·CCTV·유동인구 데이터가 이미 개방되어 있었기에 이 아이디어가 가능했다 — 수상 여부와 무관하게, 이 아이디어 자체가 '데이터 개방이 시민 안전으로 돌아오는 경로'의 실증 사례가 되기를 바란다.
