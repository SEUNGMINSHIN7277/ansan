# ■ 아이디어 개요

## 1. 배경 — 현황과 문제점

**안산의 현실.** 안산시는 외국인 주민 101,850명, 총인구 대비 15.2%로 경기도 1위의 도시다[1]. 단원구 선부동 '땟골마을'에는 국내 최대 고려인(러시아어권) 공동체가 형성되어 안산시 전체 고려인은 약 2만 3천 명으로 추산되고[2], 원곡동은 70여 개국 주민이 모인 국내 유일의 다문화마을특구다[3]. 그런데 이들의 생명을 지키는 마지막 안전장치인 **재난문자는 한국어로만 온다.** 정부가 외국인용으로 운영하는 Emergency Ready App은 영어·중국어·베트남어·태국어·일본어 5개 언어만 지원해 **안산 고려인 2만 3천 명이 쓰는 러시아어는 아예 없고**[4], 앱을 스스로 찾아 설치한 사람에게만 작동하는 '풀(pull)형' 구조다. 즉, **재난문자가 발송되어도 안산 시민 7명 중 1명에게는 사실상 닿지 않는다.**

**국가의 현실 — 실패는 반복되고 있다.** 이 문제는 언어에서 끝나지 않는다. 재난문자 체계 전체가 '발송'에서 멈춰 있고, '도달'은 아무도 책임지지 않는다. 실제 사례로 검증된 6가지 실패 지점이 있다.

| 실패 지점 | 검증된 실제 사례 |
|---|---|
| ① 감지 지연 — 신호는 있었으나 종합되지 않음 | 오송 지하차도 참사(2023.7.15): 1시간 전 119 신고와 홍수경보가 존재했으나, 지하차도 경고 문자는 **사고 2시간 29분 후** 발송[5][6] |
| ② 검증 실패 — 확신 부족의 지연과 무검증 오발령의 양극단 | 이태원 참사(2022.10.29): 첫 신고 후 **1시간 40분** 뒤 첫 재난문자, 발송 요청 78분 미처리[7][8] / 서울 경계경보 오발령(2023.5.31): 검증 없이 발송, 22분 뒤 '오발령' 정정[9] |
| ③ 문안 품질 — 행동으로 이어지지 않는 문구 | 서울 오발령 문자에는 '왜, 어디로'가 없었음[9]. "안전에 유의하시기 바랍니다"류 무행동 문구 관행 |
| ④ 표적 부재 — 전체 살포가 만드는 무관심 | 시군구 전체 일괄 발송 → 무관한 수신 반복 → 피로감에 **알림을 끄는 시민들**('스팸' 취급)[10] → 정작 위험할 때 못 보는 '양치기 소년' 악순환 |
| ⑤ 채널 단일 — 휴대폰 CBS 하나에 전부를 건다 | 알림을 껐거나, 폰을 못 보거나(운전·작업·수면), 한국어를 못 읽는 시민에게 구조적 공백 |
| ⑥ 도달 미측정 — 개선 루프의 부재 | 국가는 '몇 건 발송했는지'만 알고 '몇 %에게 닿았는지' 모른다 — 성과지표가 없어 ①~⑤가 반복 |

## 2. 해결의 필요성 — 왜 지금이고, 왜 안산인가

- **왜 지금**: 행정안전부는 2026년 하반기 재난문자를 90자→**157자로 전국 확대**한다[11][12]. 그릇은 커졌지만, 커진 그릇을 '몇 분 만에, 무엇으로 채워, 누구에게 닿게 할지'는 여전히 담당자 개인의 역량에 달려 있다. AI 기본법 시행(2026.1)[13]으로 공공 AI 활용의 법적 기반도 갖춰졌다. 2026년은 '재난 커뮤니케이션의 AI 전환'을 시작할 유일무이한 적기다.
- **왜 안산 ①(권한)**: 재난문자 발령권자에는 시장·군수·구청장이 포함되며(「재난문자방송 기준 및 운영규정」, 행정안전부 훈령)[14], 호우·폭염·한파·실종경보 등 생활재난 문자의 발령 주체가 바로 안산시다. 이 아이디어는 **안산시가 자기 권한으로 즉시 실행하는 자기 업무의 혁신**이다.
- **왜 안산 ②(필요)**: 하천 28개[15], 해안 관광지 대부도, 국가산업단지의 야외 노동, 시 단위 최고 수준의 외국인 비율 — 재난정보 도달 문제의 최대 피해 요인이 겹쳐 있는 도시다.
- **왜 안산 ③(자산)**: 감지(수위·기상·교통·CCTV)부터 도달(인구·유동·상점·전광판)까지 전 단계를 조립할 수 있는 개방 데이터가 이미 갖춰진, 전국적으로 드문 도시다(본 기획서 D1~D19, 전량 개방 확인).

## 3. 핵심과제

재난문자의 생애주기 6단계(감지→검증→작성→표적→전파→도달확인)를 공공데이터와 AI로 전환하고, 대한민국 최초로 재난 커뮤니케이션의 성능을 2개 지표로 측정·관리한다.

- **TTR(Time-to-Reach)**: 위험 신호 최초 포착 → 위험 노출 시민 도달까지의 시간. 목표 **5분 이내** (오송형 상황 2시간 29분[5] 대비)
- **Reach Rate(도달률)**: 위험 노출 인구 중 '읽고 행동할 수 있는 형태'로 받은 비율. 목표 **95% 이상** (현재 언어 기준 상한 약 85%)

## 4. 기대효과 (요약)

1. **생명**: 위험 인지→시민 도달 시간을 149분에서 5분으로 — 골든타임을 '발송'이 아닌 '도달' 기준으로 확보
2. **포용**: 러시아어권 2.3만 명을 포함한 외국인 주민 10.2만 명과 고령·저시력 시민이 처음으로 '읽고 행동할 수 있는' 재난정보를 받음
3. **신뢰**: 골목 단위 표적화로 무관 수신을 줄여 재난문자 차단 악순환[10]을 끊고 '진짜 경보'의 신뢰 회복
4. **행정**: 문안 작성·검토 자동 보조, 오발령·중복 발송 구조적 감소, 전 발령의 도달률 KPI 자동 리포트
5. **확산**: 지표·산식·아키텍처가 전국 공통 개방데이터 기반이라 226개 기초지자체에 그대로 복제 — '발송 중심→도달 중심' 국가 패러다임 전환의 출발점

## 5. 아이디어 내용 요약

> **"모두의 사이렌"은 안산시 재난문자 운영을 위한 AI 관제탑이다.** 도시의 개방 데이터(수위·기상·교통·CCTV)가 위험을 감지해 발송 검토를 발제하고, AI가 근거를 교차검증해 담당자의 확신을 만들며, 157자 문안과 러시아어를 포함한 20개 언어 행동카드를 3초 안에 작성하고, 시간대 유동인구로 발송 범위를 골목 단위로 좁히고, CBS와 동시에 도로전광판(VMS)·버스정류소·외국인 밀집 상점('동네 사이렌' 노드)·시 다국어 챗봇으로 밀어내며, 발송 직후 도달률을 계산해 다음 발송을 더 낫게 만든다. **발송 버튼은 끝까지 사람이 누른다 — AI는 시간과 확신과 도달을 만든다.**

### 1-2. 단계별 상세 동작

**① 감지 — "도시가 이상을 느낀다."** 안산 관내 하천 28개(D11) 유역의 실시간 수위(D9)·기상특보(D13)·하천범람지도(D10), 도로 구간별 교통흐름·속도(D8)의 급변, 재난감시 목적의 교차로 CCTV(D7) 위치 정보를 상시 결합 감시한다. 과거 10년 구·동별 강우량(D12)과 과거 발령 이력(D2)으로 학습한 임계 기준을 넘는 순간 '재난문자 발송 검토' 티켓을 자동 발제한다. — 오송의 교훈(신호는 있었으나 종합되지 않았다[5][6])에 대한 직접 응답.

**② 검증 — "확신을 3분 안에."** 티켓에 대해 수위+기상+교통+CCTV 화면 링크를 한 화면에 모아 신뢰도 스코어(0~100)와 신호별 기여도, 근거 묶음을 제시한다. 담당자는 근거를 보고 발송·보류·반려를 결정한다(human-in-the-loop). — '확신이 없어 78분을 흘려보내는 것'[7]과 '검증 없는 오발령'[9]의 양극단을 동시에 제거.

**③ 작성 — "157자를 3초 안에, 승인은 사람이."** LLM이 재난 유형·위치·검증 근거를 입력받아 157자 표준 골격 — 무엇이(재난)/어디서(장소)/누구는(대상)/어떻게(행동) + 가장 가까운 대피시설(D5) — 으로 문안 초안을 생성한다. 동시에 안산 주민 국적 구성(D19) 기반 우선 20개 언어(러시아어·우즈베크어·중국어·베트남어 등)와 쉬운 한국어(고령·아동·발달장애), 음성(TTS) 버전을 생성한다.

**④ 표적 — "필요한 사람에게만, 그래서 신뢰를 지킨다."** 위험 반경 내 노출인구를 행정동별 내외국인 인구(D3)와 시간대·내외국인 유동인구(D4)로 계산해 발송 범위를 읍면동·골목 단위로 제안한다. 무관 수신이 줄면 피로·차단[10]이 줄고 '진짜 경보'의 신뢰가 회복된다.

**⑤ 전파 — "CBS가 못 닿는 곳을 도시가 민다."** CBS 발송과 동시에 ▸VMS 도로전광판(D6) ▸버스정류소 안내(경기데이터드림 정류소 데이터) ▸'동네 사이렌' 상점 노드 — 세계맛집(D14)·상품권 가맹점(D15) 좌표로 선정한 외국인 밀집 상점의 사장님 폰·매장 화면 ▸안산시 26개 언어 행정챗봇(시 GovTech 실증사업)·외국인주민지원본부 채널 ▸공공와이파이 접속 안내(D16)로 언어·채널별 변형 메시지를 동시 송출한다. 취약 골목엔 노인·독거 데이터(D17)로 채널을 증설한다.

**⑥ 도달확인·학습 — "측정이 개선을 만든다."** 발령 직후 발령이력(D1·D2) × 노출인구(D3·D4) × 언어 구성(D19) × 채널 커버리지의 결정론적 계산으로 도달률·TTR을 산출하고, 언어·골목·채널별 공백 리포트를 자동 생성해 ④·⑤ 파라미터를 갱신한다.

### 2-2. 데이터 결합 스키마

- **공간 키**: 모든 좌표 데이터(D5·D6·D7·D14·D15·D16)를 WGS84로 통일 후 **H3 격자(해상도 8~9, 골목 단위)** 에 매핑. 행정동 단위 데이터(D3·D17)는 행정동↔격자 면적비 배분
- **행정 키**: 행안부 행정동·법정동 코드 + 재난문자 지역코드(D2)로 발령↔지역↔인구 연결
- **시간 키**: 유동인구(D4)의 시간대 구간을 발령 시각(D1)과 정렬(1시간 단위)

### 2-3. 핵심 산식

- **노출인구**: E(g,t) = 상주인구(D3, 야간 가중) + 유동인구(D4, 주간·시간대 가중) — 격자 g, 시각 t
- **언어별 노출**: L(g,t,lang) = E(g,t) × 해당 행정동의 국적→언어 구성비(D19)
- **도달률**: Reach = Σ L(g,t,lang)×Coverage(lang,채널조합) ÷ Σ L(g,t,lang)
  - Coverage 구성: CBS 수신율 × 언어 이해 가능 여부 + VMS 가시권(반경 300m) + 정류소 대기 + 상점 노드(반경 150m) + 챗봇 구독 — 채널별 계수는 시범 운영 실측으로 보정(초기값은 보수적 가정 명시)
- **TTR**: 신호 임계 초과 시각 → 최종 채널 송출 완료 시각 (단계별 소요 로그로 병목 자동 식별)

### 2-4. AI 세부 설계

- **감지 임계 학습**: 과거 10년 강우(D12)·과거 발령(D2)을 라벨 프록시로 XGBoost 보조 학습 — '과거에 발령했던 조건'을 기준선으로 과탐·미탐 균형
- **LLM 안전장치(3중)**: ⑴ 자유 생성이 아닌 **필드 채움 방식**(재난유형·지명·시각·대피소는 데이터 필드에서 주입 — 환각 원천 차단) ⑵ 다국어 용어집 고정(세계맛집 D14의 4개 언어 병렬 텍스트+행동요령 표준 대역어) 및 back-translation 자동 검증 ⑶ **커뮤니티 검수단**: 외국인주민지원본부·고려인지원센터와 언어별 감수 체계(시 조직 활용) — 전 생성문에 AI 표시[13]
- **설명가능성**: 검증 스코어의 신호 기여도(SHAP 방식)를 담당자 화면에 상시 표시, 전 판단 로그 보존(감사 대응)

### 2-5. 성능 검증 프로토콜 (백테스트 설계)

1. **리플레이 검증**: 2023~2025년 안산 관련 발령이력(D1·D2) 전건을 시스템에 재생 — 각 발령의 (재현된) 감지 시각 vs 실제 발령 시각 비교로 **TTR 단축분**을 정량 산출, 당시 시간대 유동인구(D4)로 **당시 도달률**을 소급 계산해 개선 폭 제시
2. **오송 반사실 검증**: 공개 타임라인[5][6]에 본 파이프라인을 대입 — 수위 임계 초과(사고 약 1시간 전 상당) 시점 기준 '회피 가능 시간 54분' 단계별 산출 — [도표 4] 타임라인 비교
3. **트리거 성능 지표**: 과거 발령 대비 정탐률(recall)·오탐률(false alarm)·리드타임 분포 보고 — 과탐 억제 기준(2신호 동시 발화) 명시

## 4. 스토리보드 (시각화)

### 1-2. 사회적 기대효과

- **경보 신뢰 자본의 회복**: '양치기 소년' 악순환[10]을 표적화로 끊어, 정말 위험할 때 시민이 반응하는 사회적 신뢰를 복원 — 재난문자 제도 자체의 실효성 회복
- **포용 사회의 실증**: "모두를 위한 AI"(AI 기본사회 국정기조)를 재난 안전에서 문자 그대로 구현 — 외국인·고령자·아동이 같은 시각, 같은 품질의 안전 정보를 받는 도시
- **행정 혁신의 전범**: 담당자 1인의 역량·심리에 걸려 있던 재난 커뮤니케이션을 데이터·AI·프로세스로 시스템화 — 오발령·지연의 구조적 원인 제거, 감사 가능한 판단 로그
- **산업·노동 안전 연계**: 폭염 모듈은 온열질환 최다 발생장소가 '작업장'이라는 국가 통계[16]에 따라 반월·시화 산단 야외 노동자(외국인 다수)에게 우선 도달 — 산업도시 안산의 노동 안전망 강화
- **국가 파급**: 도달률·TTR 지표와 산식·아키텍처는 전국 공통 개방데이터(D1·D2+각 지자체 인구·유동)로 구성되어 226개 기초지자체에 복제 가능 — 외국인 주민 258만 시대의 '발송 중심→도달 중심' 국가 재난 커뮤니케이션 전환의 첫 실증

## 2. 아이디어의 현실성 및 지속가능성

### 2-1. 현실성

- **권한**: 발령권자에 시장·군수·구청장 포함[14] — 본 시스템의 전 단계가 안산시 권한 내 업무이며, 시 권한 밖 재난(민방공 등)은 '중계·다국어화'로 역할을 한정해 거버넌스 충돌이 없음 (§1-3 매트릭스)
- **데이터**: 활용 데이터 전량(D1~D20)이 공공데이터포털·경기데이터드림에 현재 개방되어 있음을 개별 확인(2026.7, URL 명기). 노출인구·도달률은 예측이 아닌 **개방 데이터의 결정론적 계산**이라 모델 불확실성 논쟁과 무관. 유동인구(D4)는 통신 기반 추정 자료이므로 '노출 인구의 근사'로 명시하고 보조 변수로 사용
- **인프라**: VMS·CCTV·챗봇·지원본부 등 시 보유 자산을 채널로 쓰므로 신규 하드웨어 투자가 불요. 소프트웨어는 오픈소스 스택(Python·PostGIS)+개방 API로 라이선스 비용 0 — 시 스마트도시 통합플랫폼의 1개 모듈로 탑재 가능한 규모
- **책임 구조**: 발송 결정·문안 승인·범위 확정 3개 관문 전부 human-in-the-loop, 전 판단 로그 보존, AI 생성물 표시[13] — AI 기본법 및 재난문자 운영규정[14] 정합

### 2-2. 지속가능성

- **연중 운영**: 호우(여름)→폭염(D18·D20)→한파·대설(겨울)→실종경보·미세먼지·화재(연중)까지 동일 파이프라인이 재난 유형만 바꿔 운영(§1-3) — 계절성 없는 상시 시스템이므로 투자 대비 가동률이 높음
- **정책 정합·확장 경로**: 행안부 157자 개편(2026 하반기 전국)[11][12]의 실행 도구로 편승 → 최우수 선정 시 제14회 범정부 창업경진대회 통합본선(아이디어 기획 부문)에서 '안산 실증→전국 표준' 서사로 연결 → 도달률 KPI의 국가 표준화 제안
- **운영비 구조**: 상시 비용은 서버·LLM API 호출(발령 시에만 집중 발생) 수준으로 경량. 다지자체 공동 활용(재난문자 코파일럿) 시 유지비 분담 구조로 확장 가능
- **예상 한계와 대응 (정직한 기술)**:

| 예상 질문·한계 | 대응 |
|---|---|

# ■ (자유 기재)

**1. 왜 '안산'이 이 아이디어의 주인인가.** 안산은 '전달되지 않은 경고'의 무게를 대한민국에서 가장 깊이 아는 도시다. 세월호의 도시 안산이 "모든 시민에게, 제시간에, 알아들을 수 있는 말로 닿는 경보"의 전국 표준을 만든다는 것 — 이것은 기술 과제를 넘어 도시의 서사이며, 안전도시 브랜드·다문화 정주 여건·산단 노동 안전이라는 안산시 발전 과제에 직결된다.

**2. 유사 서비스와의 차별성 (공개검증 대비 요약표).**

| 기존 | 성격 | 모두의 사이렌과의 관계 |
|---|---|---|
| 긴급재난문자(CBS) | 한국어 일괄 발송 | 대체가 아닌 **운영 지능화** — CBS는 그대로, 앞뒤 단계를 AI로 |
| Emergency Ready App[4] | 5개 언어 풀형 앱(러시아어 없음) | 보완 — 앱 설치와 무관하게 도시가 미는 푸시형·20개 언어 |
| 안전디딤돌 앱 | 재난정보 포털 앱 | 보완 — 설치 기반 한계 동일, 본 시스템의 채널 중 하나로 연동 가능 |
| 행안부 157자 개편[11][12] | 글자수·중복 방지(그릇) | **개편의 실행 도구** — 커진 그릇을 채우는 AI |

| 재난 예측 AI(기상청 등) | 위험 '예측' 고도화 | 상류 보완 — 본 시스템은 '전달'의 마지막 1km 담당 |

**3. 실행 준비와 약속.** 본 팀은 1차 통과 시 2차 발표(7.30)까지 실데이터 데모를 완성해 시연한다: ▸안산 관련 재난문자 발령이력(D1·D2) 리플레이 ▸골목 단위 도달 격차 지도 ▸러시아어·쉬운 한국어 행동카드 실시간 생성. 전 데이터가 무료 개방 자료이므로 별도 조달 절차가 없다.

**4. 확장 로드맵.** ▸1단계(안산 시범): 호우·폭염 시즌 병행, 도달률 baseline 실측 ▸2단계(경기도): 경기데이터드림 유동인구 기반 31개 시군 확산 ▸3단계(전국·제도화): 행안부 재난문자 개편과 연계한 '도달률 KPI' 표준 제안 ▸4단계(글로벌): 미국 WEA·일본 J-Alert도 표적·도달 측정은 미해결 영역 — 다국어 재난 커뮤니케이션 K-모델로 CAP(국제 공통경보프로토콜) 생태계 진출.
