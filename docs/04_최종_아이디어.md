## 1. 문제 정의 (Why)

1. **국가 문제**: 외국인 주민 258만 명(2024.11 기준 행안부, 총인구 5.0% 첫 돌파, 역대 최다). 그러나 건강관리 체계는 내국인 중심 — 외국인 근로자는 건강검진 수검률이 낮고, 언어장벽·정보 부족·장시간 노동으로 질병을 키운 뒤에야 병원에 간다. 산재·의료 사각지대는 이미 사회적 비용으로 되돌아오고 있다 (뿌리산업 인력 삼중고, E-9 2026년 8만 명 도입).
2. **안산 문제**: 외국인 주민 10.1만 명(13.3%, 전국 최상위), 원곡동 국내 유일 다문화특구(70개국 7만 명), 반월·시화 산단의 실질 노동력. 시 보건소(상록수·단원 + 대부·원곡 보건지소)의 한정된 자원으로 어느 동네·어느 집단부터 찾아가야 하는지 **데이터 기반 우선순위가 없다**.
3. **서비스 공백**: 기존 서비스(1345 전화상담, 하이코리아 민원, EPS 취업행정, 안산 행정민원 챗봇(실증 중), 인천 심토미 증상문진)는 전부 **"찾아온 사람에게 반응"**하는 구조. **"위험한 사람을 먼저 찾아가는"** 예측·예방형 서비스는 전국에 없다.

## 2. 서비스 개요 (What) — 3-레이어 구조

**제품 정체성: 보건소·정책부서가 쓰는 행정 인텔리전스 도구** (2025 수상작 5건 전원이 '시정 분석·관리 도구'였던 심사단 선호 패턴에 부합; 1호 적용 대상이 외국인 주민)

```
[L1 스코어링] 사각지대 레이더       [L2 연계] 기존 채널 공급 API          [L3 행정] 자원배치 시뮬레이터
 수검률 실계산(구 단위) +           시 다국어 챗봇(실증 중)·1345·        찾아가는 검진버스·의료통역·
 동 단위 우선순위 합성추정     →    지원본부 채널에 "누구에게 무엇을" →   보건소 자원의 최적 배치와
 (검증된 2개 데이터 결합)           계산 결과를 공급 (새 앱 없음)         정책 효과 사전 시뮬레이션
```

- **L1 사각지대 레이더 (AI 스코어링)**: ① 건보공단 안산시 외국인 건강검진 통계(15118612: 구×성×연령 수검자수·흡연·음주·신체활동)와 ② 월별 시군구별 외국인 건강보험 적용인구(15129529: 분모)를 결합해 **구×성×연령 수검률을 실제 계산**하고, ③ 행정동별 내외국인 인구구조 + 유동인구 + 산단 입주기업(업종·종업원수) + 의료 접근성(보건소·약국·상비약 판매점 거리)을 합성 추정(synthetic estimation)으로 결합 → **동 단위 "검진 사각 우선순위 스코어" 지도** 생성 (예: "성·연령·외국인 비중·업종 구조상 수검률 최하위 추정 동네 TOP 5와 근거"). ※ 관측 해상도(구 단위)의 한계와 추정 방법론을 기획서에 정직하게 명시 — 시범운영으로 동 단위 실측 축적 로드맵 제시
- **L2 연계 인터페이스 (예방 실행)**: 우선순위 지역에 대한 선제 검진 안내는 **시가 이미 실증 중인 다국어 행정민원 챗봇·1345·외국인주민지원본부 채널에 API로 공급** — 새 앱을 만들지 않고 기존 시 투자와 상호보완 (본 도구는 "어디에·누구에게·무엇을 보낼지"를 계산해 공급하는 두뇌 역할)
- **L3 정책 시뮬레이터 (행정 의사결정)**: 검진버스·의료통역사·보건지소 인력의 최적 배치(최적화 알고리즘), "검진율 +10%p 달성에 필요한 자원" 역산, 정책 효과 사전 시뮬레이션 대시보드

## 5. 기대효과 (심사항목 "효과성" — 정량화 로직)

**안산시 (1차 심사 어필)**
- 수혜자: 외국인 주민 10.1만 명 + 내국인(감염병·응급 대응력은 전 시민 편익)
- 보건행정: 검진버스·통역 자원의 데이터 기반 배치 → 동일 예산으로 도달률 상승 (기획서에서 현재 수검률 대비 목표 +10%p 시나리오 제시)
- 조기발견 의료비 절감: 만성질환 조기개입 시 1인당 연간 의료비 절감 (건보 통계 기반 추정치 산출) × 위험군 규모
- 산단 경쟁력: 외국인 근로자 건강 = 반월시화 뿌리산업 가동률 (인력 삼중고 완화)
- 다문화특구 정주여건 개선 → 인구감소(2023 68.9만→2026 66.5만) 방어

**국가 (범정부 본선 어필)**
- 확장 대상: 외국인 주민 258만·전국 시군구 (경기 84.5만, 특히 화성·시흥·수원 등 인접 밀집지), 지역특화형 비자 107개 지역 (인구감소지역의 외국인 유치 경쟁 → "정착 인프라"가 승부처)
- 일반화: "외국인" 모듈을 노인·장애인 등 다른 데이터 사각지대 계층으로 교체 가능한 **"포용 AI 표준모델"** — 행안부 2026 공공AI 지원사업(180억)·AI 기본사회 국정과제와 직결
- 데이터 정책 제언 포함: 건보공단 외국인 검진 통계의 전국 시군구 단위 개방 확대 요청 (안산 데이터가 그 가치를 실증) — "데이터 개방을 이끌어내는 아이디어"는 주최기관(행안부) 최고 선호 유형

## 6. 차별화 방어 논리 (심사 Q&A 대비)

| 예상 질문 | 방어 |
|---|---|
| "안산시가 하는 챗봇과 뭐가 다른가?" | 챗봇 = 묻는 말에 답하는 행정민원 Q&A(반응형). 다봄케어 = 묻지 않은 위험을 먼저 찾아가는 건강 예측·예방(선제형). 챗봇에 '건강 모듈'로 플러그인 가능한 보완재 — 시 투자의 2단계 |
| "인천 심토미와 뭐가 다른가?" | 심토미 = 아픈 개인이 증상 입력 후 병원 안내(사후). 다봄케어 = 집계데이터로 위험 집단을 사전 발굴 + 행정자원 최적화(사전). 층위가 다름 (개인 진료 안내 vs 도시 보건 인텔리전스) |
| "개인정보는?" | 개인 건강기록 미사용 — 공개된 집계 통계 기반 소지역 추정. 개인 접점은 옵트인 자가문진뿐. AI 기본법 투명성 의무 선제 반영 |
| "데이터가 통계(집계)뿐인데 예측이 되나?" | SAE(소지역추정)는 집계→소지역 추론의 검증된 방법론(통계청 활용 사례). 정확도 한계는 정직하게 명시하고 '자원 배치 우선순위' 용도로 스코핑 — 과대포장 회피 |
| "왜 안산인가?" | 전국 유일 데이터(건보 안산 외국인 검진 통계) × 전국 최고 외국인 비율(13.3%) × 유일 다문화특구 × 국가산단 = 이 문제의 전국 최적 실증지 |
