# 안산시 공공데이터 카탈로그 (2026-07-05 조사)

> **조사 방법**: 공공데이터포털(data.go.kr)·경기데이터드림(data.gg.go.kr)·안산시청 사이트는 해외/데이터센터 IP와 봇 접근을 WAF로 전면 차단(HTTP 403)하고 있어 직접 크롤링이 불가능했다. 대신 **Google 검색 인덱스(Googlebot은 허용됨)를 통한 열거 방식**으로 우회하여, 4개 주제 영역 × 총 200여 회의 도메인 한정 검색으로 데이터셋 상세 페이지를 수집했다.
>
> **한계**: 제목·수정일자는 검색 인덱스 스냅샷 기준이므로 실제 포털에서 최신 버전 확인 필요. 검색 인덱스에 노출되지 않은 데이터셋은 누락됐을 수 있다 (전체 목록은 아래 '기관별 전체 목록 허브 URL'에서 국내망으로 직접 확인 권장).

## 10. 조사에서 드러난 데이터 갭(공모전 차별화 포인트)

1. **안산시 단독 오픈API 부재** → "안산시 데이터를 API·대시보드로 서비스화"하는 기획 자체가 차별화 요소가 될 수 있음
2. **외국인·다문화 데이터가 타 도시 대비 풍부** (내외국인 행정동별 인구, 외국인 건강검진, 원곡동 상권 3종, 세계맛집 다국어 데이터) → 안산만의 독보적 주제
3. **교통 데이터 최신·고밀도** (2025년 등록 교통흐름·속도 통합정보, 교차로 CCTV, VMS 2종) → ITS/AI 영상분석 기획과 직결
4. **시계열 데이터 존재** (일별 강우량 10년치, 상수도 유량, 하수 방류수질, 유동인구) → 예측모델(AI 활용 점수) 적용 용이
5. **공간(SHP) 데이터 개방** (도시지역·공간시설·방화지구) → GIS 중첩분석 가능
6. 전기차충전소·대기질·어린이보호구역 등은 **전국 데이터로 보완 필수** — 기획서에 출처를 정확히 구분 명시할 것
