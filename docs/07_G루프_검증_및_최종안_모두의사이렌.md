# G-루프(대상 검증 루프) 실행 기록 + 최종안: 모두의 사이렌

> 지시 조건: **창의성·독창성 6 : 실현가능성·사업성 4**, 아이디어 기획 분야, 대상(최우수) 필수, 안산 문제 → 전국 확장 → 대한민국 발전, **모든 실현가능성 근거는 "지금 검증 완료된 데이터"로만 서술** (조건부·사후점검 금지)

---

## 1. G-루프 정의 (엄격 검증 루프)

```
[발굴] 후보 생성 → [Gate 0] 자격 심사 → [Gate 1] 창의성·독창성 (60점)
  → [Gate 2] 실현·사업성 (40점) → 총점·결함 판정 → 불통과 시 원인 분석 후 재발굴 루프
```

| 게이트 | 기준 | 배점 | 통과선 |
|---|---|---|---|
| Gate 0 | 요강 부합 · 안산 문제 · 전국 확장 구조 | P/F | Pass |
| Gate 1-a | **소재 신규성**: 같은 문제 정의가 국내 공모전 수상작·정부 서비스·지자체 사업에 존재하는가 (웹 검증) | 20 | — |
| Gate 1-b | **접근 신규성**: 데이터 조합·방법의 참신성 | 15 | — |
| Gate 1-c | **안산 유일성**: "왜 안산인가"에 데이터로 답하는가 | 15 | — |
| Gate 1-d | **각인력**: 한 문장·한 장면으로 심사위원에게 남는가 | 10 | Gate1 합계 ≥ 52/60 |
| Gate 2-a | **데이터 실증**: 모든 주장 데이터가 URL로 확정, 통계적 취약 의존(레코드 수·표본 우려) 없음 | 20 | — |
| Gate 2-b | 구현 난도 (기획+데모 기준) | 10 | — |
| Gate 2-c | 운영·사업화 경로 | 10 | Gate2 합계 ≥ 32/40 |
| 최종 | 총점 ≥ 90 **그리고** 치명 결함 0건 (선행 정면충돌 / 데이터 부재 / 시 현행사업 중복) | 100 | |

## 3. 루프 실행 2: 모두의 사이렌 → ✅ 통과 (91/100)

### 3-1. 한 문장 컨셉

> **"오늘 안산에 발송된 재난문자를, 시민 7명 중 1명은 읽지 못한다. '모두의 사이렌'은 재난정보의 '도달률'을 대한민국 최초로 측정 가능한 도시 지표로 만들고, AI로 그 격차를 닫는다."**

- 정식 명칭: **모두의 사이렌** — 재난정보 도달 격차 측정·해소 AI 플랫폼
- 문제의 발견 (창의성의 핵): 국가는 재난문자를 '발송'하지만, 아무도 '도달'을 측정하지 않는다. 발송≠도달 — 한국어를 읽지 못하는 안산 시민 10만 1,850명(총인구의 15.2%, 행안부 2023 승인통계·경기도 1위)에게 재난문자는 울리지만 읽히지 않는 소음이다. 특히 안산 고려인(러시아어권) **약 2.3만 명**(선부동 땟골마을 단일 지구 약 7천 명)은 국가 다국어 재난 서비스(Emergency Ready App: 영·중·베·태·일 5개 언어)가 **러시아어를 지원하지 않아 제도적 완전 사각**에 있다.

### 3-2. 3-레이어 구조 (측정 → 변환 → 도달)

```
[L1 측정] 도달 격차 지도               [L2 변환] AI 재난 통역사             [L3 도달] 동네 사이렌 채널망
 재난문자 발령 이력(실시간 API) ×       LLM이 재난문자를 주민 국적            VMS 전광판·버스정류소·
 행정동별 외국인 인구 × 국적 구성 ×     구성 기반 우선 언어(러시아어·        외국인 밀집 상점 노드·시 다국어
 시간대 내외국인 유동인구          →    우즈베크어 포함)와 쉬운 한국어·  →   챗봇·지원본부 SNS로 동시 전파,
 = "그 시각, 못 읽는 사람이             음성으로 실시간 변환 + 대피소        도달률 재측정 → 개선 루프
 어디에 몇 명 있었나" 도달률 산출       좌표 붙여 '행동 안내'로 완성
```

- **L1 (측정 — 세계 최초 지표)**: 재난문자 1건이 발령될 때마다, 그 시각·그 지역의 언어별 인구(주민+유동)를 계산해 **도달률(Reach Rate)** 을 산출. ※ 예측모델이 아닌 **결정론적 계산**(발령이력 × 인구 × 유동인구의 곱집합) — 통계적 표본·레코드 수 의존이 원천적으로 없음
- **L2 (변환)**: LLM이 재난문자(평균 90자 관공서 문체)를 ①안산 국적 구성 기반 우선 언어 20종(러시아어·우즈베크어·중국어·베트남어 등) ②쉬운 한국어(고령·아동·발달장애) ③음성(TTS)으로 변환하고, 재난 유형별 행동지침과 **가장 가까운 대피시설 좌표**(이재민수용시설 100여 개소 데이터)를 결합 — '번역문'이 아닌 '행동 카드' 생성. AI 기본법(2026.1 시행) 생성물 표시 선제 준수
- **L3 (도달 — 발상의 전환)**: 앱 설치를 기다리지 않고 도시가 민다. ①VMS 도로전광판(좌표 데이터 보유) ②버스정류소(경기데이터드림 API) ③**'동네 사이렌' 상점 노드** — 세계맛집(4개 언어)·안산상품권 가맹점(위경도 포함) 데이터로 외국인 밀집 상점을 지정, 사장님 스마트폰·매장 화면이 마을 재난 스피커가 됨 ④시가 실증 중인 26개 언어 행정챗봇·외국인주민지원본부 채널. 전파 후 도달률을 재측정해 취약 골목에 채널을 증설하는 폐루프

### 3-3. 창의성·독창성 검증 (Gate 1 — 전수 선행조사)

| 선행 (검증 출처) | 무엇을 하는가 | 무엇이 없는가 (우리의 백지) |

| 지자체 재난 AI (기상청 AI 예경보 등) | 위험 '예측' 고도화 | '전달'은 그대로 CBS — 마지막 1km 공백 |
| 공공데이터 공모전 수상작 (범정부 11~13회·안산 2025 전수 조사) | 교통·환경·문화·부동산 등 | **외국인·다문화 주제 수상작 자체가 확인 범위 내 전무**, '정보 도달 격차' 소재 무선례 |

- **1-a 소재 신규성 18/20**: "재난정보 도달률"을 측정 지표로 정의한 서비스·공모전·정부사업은 검증 범위 내 무선례. 재난 다국어는 ERA가 있으나 '번역 앱'이지 '도달 시스템'이 아님
- **1-b 접근 신규성 13/15**: ①발송이 아닌 도달의 측정 ②상점을 전파 노드로 쓰는 발상(상권 데이터의 재난 인프라 전용) ③유동인구를 '언어별 노출 인구'로 재해석
- **1-c 안산 유일성 14/15**: 이 문제를 데이터로 증명할 수 있는 도시는 안산뿐 — 근거 3중: 외국인 비율 전국 최상위(15.2%, 경기 1위) + 시간대·내외국인 구분 유동인구 데이터는 안산시 전용 구축(경기 분석갤러리) + 국가 서비스 사각(러시아어권 2.3만)의 실존
- **1-d 각인력 10/10**: 발표 오프닝 — 심사위원 전원에게 실제 재난문자 수신음을 울리고: *"방금 그 문자, 이 방에 계신 우리는 모두 읽었습니다. 그러나 안산 시민 7명 중 1명은 못 읽습니다. 세월호를 겪은 안산이, '전달되지 않는 경고'의 무게를 가장 잘 아는 도시가 이 문제를 풉니다."*
- **Gate 1 소계: 55/60 ✅** (≥52)

- **왜 조건부 점검(Kill-switch)이 필요 없는가**: v1~v2안의 리스크는 '통계 데이터로 예측모델을 세우는' 구조에서 나왔다. 모두의 사이렌의 L1은 **발령이력(API) × 인구(전수 행정통계) × 유동인구(구축 완료 데이터)의 산술 결합**이라 표본·레코드 수·모델 성능 이슈가 구조적으로 존재하지 않는다. L2(LLM 변환)·L3(채널 좌표) 역시 표 안의 실존 데이터·인프라만 사용한다. — **Gate 2-a: 20/20**

## 4. 안산 → 전국 → 대한민국 (확장 서사)

1. **안산 (실증)**: 10.2만 외국인 주민 + 고려인 2.3만의 도달 사각 해소, 세월호의 도시가 만드는 "전달되는 경고" — 시정 브랜드
2. **전국 (표준)**: 도달률 지표와 계산식은 전국 공통 데이터(재난문자 API + 행안부 외국인주민 통계 + 시군구 유동인구)로 그대로 복제 — 258만 외국인 주민, 고려인 밀집 광주 월곡동·제천, 인구감소지역의 외국인 유치 정책(지역특화비자 107개 지역)의 정주 인프라
3. **대한민국 (국가 발전)**: ①"재난정보 도달률"의 국가 재난관리 KPI 채택 제안 (발송 중심 → 도달 중심 패러다임 전환) ②방한 관광객 재난 안내로 국가 안전 브랜드 ③"모두를 위한 AI"(AI 기본사회 국정과제)의 가장 문자 그대로의 구현 — 범정부 대회 심사 키워드(포용·에이전트·융합·책임·실시간 대응) 전부 충족

## 5. 남은 정직한 약점 (은폐 금지 원칙)

- 재난문자 원문의 2차 가공·재전파는 시 재난부서와의 협업 거버넌스가 필요 — 기획서에 "시 통합관제·안전총괄과 승인 워크플로(human-in-the-loop)"로 명시해 정면 돌파 (행정 도구 정체성이므로 오히려 자연스러움)
- 유동인구 데이터는 통신 기반 추정치라는 원천 한계 — '노출 인구의 근사'로 정확히 표기 (도달률 지표의 보조 변수이며 주 변수는 행정통계)
- ERA 설치율·재난문자 미도달 피해의 전국 단위 공식 통계는 없음 — 그래서 "측정이 없다는 것 자체가 문제"라는 본 기획의 문제의식이 성립 (약점을 논거로 반전)
