## 핵심 일정

- **접수 마감: 2026. 7. 10.(금)** — 이메일(shirone22@korea.kr) 또는 등기우편
- 1차 서류심사: ~7. 17.(금) → 상위 5팀
- 2차 발표심사: 7. 30.(목) 예정, 15분 발표
- 심사 최우선 항목: **공공데이터 활용 > AI 활용** (동점자 판정 순서이기도 함)

## 데이터 조사 방법 요약

공공데이터포털(data.go.kr)·경기데이터드림·안산시청 웹사이트는 봇/해외IP 접근을 WAF로 차단(HTTP 403)하고 있어, Google 검색 인덱스를 통한 도메인 한정 열거 방식(주제어 200여 회 검색)으로 데이터셋 목록을 수집함. 상세 방법론과 한계는 카탈로그 문서 서두 참조.
